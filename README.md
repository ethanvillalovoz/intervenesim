# InterveneSim

InterveneSim is a simulation-only benchmark for studying whether targeted recovery
interventions teach robot policies more efficiently than collecting the same amount of
additional successful demonstration data.

The project is designed for Apple Silicon and CPU-only machines. It uses MuJoCo,
robosuite, and compact PyTorch policies; no paid services or proprietary dependencies are
required.

> Status: active implementation. Reproducible commands and benchmark results will be added
> as the end-to-end pipeline is validated.
